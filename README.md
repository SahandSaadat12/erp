# ERP Project Management System

**A desktop ERP application for project management, contracts, expenses, and workflow tracking.**

یک نرم‌افزار مدیریت پروژه و هزینه‌ها با پایتون، رابط کاربری گرافیکی مدرن و پایگاه داده SQLite؛ طراحی‌شده برای مدیریت متمرکز اطلاعات پروژه‌ها، قراردادها، هزینه‌ها و مراحل اجرایی.

---

## معرفی پروژه

این پروژه یک نرم‌افزار دسکتاپ برای مدیریت فرایندهای مرتبط با پروژه است که تلاش می‌کند اطلاعات مهم را در یک محیط یکپارچه، قابل مدیریت و قابل پیگیری جمع‌آوری کند.

تمرکز اصلی پروژه روی ساختاری ماژولار، اعتبارسنجی اطلاعات، کنترل دسترسی، ثبت تغییرات و امکان توسعه‌ی قابلیت‌های جدید است.

## قابلیت‌ها

### مدیریت پروژه‌ها
- ایجاد، مشاهده، ویرایش و حذف پروژه‌ها
- مدیریت مراحل اجرایی و درصد پیشرفت
- نمایش اطلاعات و وضعیت پروژه‌ها
- پشتیبانی از بایگانی و بازیابی اطلاعات

### مدیریت قراردادها
- ثبت و مدیریت قراردادها
- مشاهده و ویرایش اطلاعات قراردادها
- ارتباط با سایر بخش‌های مرتبط برنامه

### مدیریت هزینه‌ها
- ثبت و مدیریت هزینه‌های پروژه
- دسته‌بندی هزینه‌ها، از جمله:
  - مواد و مصالح
  - حقوق و دستمزد
  - حمل‌ونقل
  - تجهیزات
  - سایر هزینه‌ها
- مدیریت وضعیت پرداخت
- اعتبارسنجی مقادیر مالی

### داشبورد و گزارش‌ها
- نمایش اطلاعات مدیریتی در داشبورد
- نمودارهای مرتبط با پروژه‌ها
- مشاهده‌ی وضعیت و پیشرفت پروژه‌ها
- ابزارهای کمکی برای تحلیل اطلاعات

### مدیریت کاربران و دسترسی‌ها
- رابط ورود کاربران
- مدیریت نقش‌ها و مجوزها
- بررسی مجوزها در عملیات پایگاه داده
- ثبت رویدادها و تاریخچه‌ی فعالیت‌ها

### امکانات تکمیلی
- مدیریت اسناد پروژه‌ها
- مدیریت مراحل و نقشه‌ی راه پروژه
- بایگانی اطلاعات
- پشتیبانی از تاریخ شمسی در رابط کاربری
- ابزارهای پشتیبان‌گیری و مدیریت پایگاه داده
- رابط کاربری قابل تنظیم و چند تم گرافیکی

> جزئیات هر قابلیت و میزان تکمیل آن را می‌توان با بررسی نسخه‌ی فعلی کد و مستندات پروژه مشخص کرد.

## نصب و اجرا

### پیش‌نیازها

- Windows
- Python 3.12
- Git

### ۱. دریافت پروژه

```bash
git clone https://github.com/SahandSaadat12/erp.git
cd erp
```

### ۲. ساخت محیط مجازی

```bash
python -m venv .venv
```

فعال‌سازی در Windows:

```powershell
.venv\Scripts\Activate.ps1
```

اگر از Git Bash استفاده می‌کنید:

```bash
source .venv/Scripts/activate
```

### ۳. نصب وابستگی‌ها

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### ۴. اجرای برنامه

```bash
python main.py
```

اگر برای راه‌اندازی اولیه یا مجوز برنامه تنظیمات اضافی لازم باشد، دستورالعمل‌های مربوط به آن باید در مستندات پروژه ارائه شوند.

---

## اجرای تست‌ها

برای اجرای تست‌ها، ابتدا وابستگی‌های موردنیاز آزمون را نصب کنید. اگر پروژه از `pytest` استفاده می‌کند:

```bash
python -m pytest tests/ -v
```

و برای بررسی خطاهای نحوی فایل‌های پایتون:

```bash
python -m compileall -q .
```

نتایج آزمون‌ها به نسخه‌ی کد و محیط اجرا وابسته‌اند؛ بنابراین هیچ نتیجه‌ی تستی بدون اجرای مجدد به‌عنوان تضمین نسخه‌ی فعلی در نظر گرفته نمی‌شود.
